# Typing Speed Tester Using Python

## About the Project
A Python-based application that evaluates typing performance by asking users to type a given sentence and displaying their results.

## Features
- Displays sentences for users to type.
- Measures typing speed.
- Calculates Words Per Minute (WPM).
- Evaluates typing accuracy.
- Displays typing performance results.

## Technologies Used
- Python
- JSON
- File Handling

## Project Files
- `typing_speed.py` – Main application.
- `sentences.json` – Contains sentences used for typing tests.
